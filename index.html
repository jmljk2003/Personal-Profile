Case 02Change Management Review+

Control flow

  1. Request
  2. Approval
  3. Testing
  4. Deployment

Scope

Change requests, approvals, testing, deployment and segregation of duties.

Approach

  1. Understand change lifecycle
  2. Identify approval requirements
  3. Review evidence
  4. Trace selected changes
  5. Evaluate control consistency

RiskUnauthorised or inadequately tested changes may affect system integrity or availability.

Control flow

  4. Resolve

Job scheduling, batch processing, monitoring, incident handling and operational handovers.
